# msp3PaymentSkeleton для MiniShop3

Каркас платёжного модуля MiniShop3 (MODX 3, beta).

## Что входит

- Способ оплаты по ссылке
- Webhook ядра и запасной пакетный URL
- Чеки 54-ФЗ
- Вкладка заказа: попытки, возврат, отмена, синхронизация
- Секреты в properties способа оплаты

## Требования

MiniShop3 >= 1.14.0-beta1, PHP 8.2.

Это шаблон для нового провайдера, не готовый шлюз.
